# Auras and fields paintings — Session B

Ten source sheets for the RPG-SPELLS art brief, following movement-toolkit
(Session A) and healers & revives (Session C).
This batch is independent and adds no game code or simulation changes.

The 10 sheets:
- `aura-protection`: Holy golden shield-rune ring ground loop + rising shield-glint motes loop.
- `spirit-guardians`: Radiant holy/pale-blue ring ground loop + translucent winged guardian spirit motes loop.
- `aura-rot`: Creeping sickly green rot stain ground loop + foul toxic green spore motes loop.
- `storm-cloud`: Roiling dark thundercloud ground loop + lightning bolt strike impact once.
- `mana-font`: Glowing violet-blue arcane rune circle ground loop + rising mana orb motes loop.
- `healing-mist`: Soft green-white healing mist ground loop + radiant leaf of light motes loop.
- `cloud-of-daggers`: Whirling black feather-blades ground loop + spinning feather-blade motes loop.
- `slow-field`: Glowing clock-face of light ground loop + floating hourglass of sand motes loop.
- `spike-growth`: Bristling 3x3 thorns and caltrops ground loop + jabbing upward thorns impact once.
- `bardic-notes`: Flowing musical staff lines ground loop + dancing musical note motes loop.

All sheets are structured as 256x256 px cells with an 8% clear margin on a fully transparent background.
Validated against `tools/spell-fx/import-spell-art.py art-source/spell-fx --check`.
