# INT-324: hero skin, face and alpha-hole fixes (PR #324)

Branch `claude/int-324`: the owner's PR #324 (`fix/hero-assets-skin-faces`) with `origin/main` merged in (a merge commit).

## What the PR brings that is kept

- `tools/ascended/pack.cjs`: restores enclosed pinholes (8 px or fewer) that background removal punched into the awakened
  sheets. The 98 `src/art/awakened/awakened_*.png` sheets go from 7,865 enclosed pinhole pixels on main to 0.
- `tools/heritage/import-art.py`: the painted portraits keep their soft edge but clamp the soft interior alpha to solid, and
  are written at 640x960 (quality 94) instead of 320x480. The 46 `src/art/heroes/*-portrait.webp` files are re-imported
  (each about 100 KB bigger, so the bundle and the offline cache grow by roughly 4 to 5 MB).
- `tools/heritage/strip.py`: the before/after strip falls back to the source sheet when no re-toned copy exists.
- The `awakened-*.webp` scene art was re-exported too (a few bytes different).

## What was dropped, and why

The PR branched at 0.262.0, and main has since done the same face job its own way (0.329.0 "cleaner faces",
`docs/notes/heritage-faces.md`). On merging:

- `tools/heritage/recolour.py` and the 24 conflicting re-toned `hero_res_*` sheets: main's versions are kept. The PR's
  rewritten skin rules would undo the 0.329.0 faces.
- `tools/heritage/heroes.json` and `sheets.json`: main's versions are kept. With main's `recolour.py`, the PR's extra
  per-hero settings make no pixel difference (checked: regenerating all 23 sheets gives identical pixels), so they were
  dead settings. `python3 tools/heritage/recolour.py` on this branch reproduces main's sheets exactly.
- `docs/samples/heritage-*.png`: left as main has them (they showed the PR's old tool output).
