# INT-325: the ornate "Keep & Kingdom" restyle (PR #325)

Branch `claude/int-325`: the owner's `feat/complete-ui-overhaul` with `origin/main` merged in (a merge commit; the PR branched at 0.262.0, so
main had moved a long way: only `build.mjs` conflicted).

## What the PR is

`src/ornateMenus.css` (new, about 1,700 lines) restyles buttons and the menus and popups; `src/index.html` gets new markup for `#ask`, `#autoSum`,
`#settings` (header), `#tip` and `#turnUp`; `build.mjs` inlines the new sheet. `test/summon-stones.test.ts` only normalises a Windows path
slash. Notes: `docs/notes/complete-ui-overhaul.md`.

## Merge

`build.mjs`: main's long `KEEP_KINGDOM_CSS` list plus `ornateMenus.css` last, so the restyle wins ties. The sheet is inlined into `index.html`
(no new file to cache); the two images it loads by URL (`ui/page.png`, `ui/battle-crest.png`) are already in the service worker's list
(checked in `out/web/sw.js`). CSS braces balance (206 and 206).

## What broke, and the fix (all in the PR's own sheet)

- **A test failed**: `no-flicker` forbids a looping animation that changes brightness; `turnUpPulse` (the upright prompt's medallion) pulsed
  its glow. The glow is now steady and only the size breathes. The test is untouched.
- **Tap targets under 44 px**, made 44 px (`TAP FLOOR` block at the end of the sheet): Settings Close, the tutorial's Skip and Got it, the
  hero sheet's Back, the party's Back, Auto-pick and search box, the dialogs' buttons, the castle's chips, portal chips and Upgrade buttons,
  the tavern's Quests, Upgrades, Trophies, All heroes and room tabs, and the spellbook's buttons (Rank up).
- **Overflow at 360 px**: the Codex's six tabs ran past the screen edge ("Legends" cut off); they now shrink (13 px, `min-width: 0`).
- **Small text**: the eyebrows (`.cardEyebrow`, `.settingsEyebrow`, `.tipEyebrow`) and the "New" dot were 10 px; now 11 px.
- **"Spire / Tower"**: no player-facing text in the PR said it (the visible strings are "Royal Dispatch", "Stand Upright" and so on). The CSS
  section heading, a comment and the PR's note did; they now say Calamity map and Last Stand. (`#towerMap` is the Calamity map's real id and
  stays. "Arcane Spire" and "Archivist Spire" are castle buildings, not the old mode.)

## Left as it was (not this PR's)

- The camp's quiet "Party" label under the Choose Your Battle bar (`#hmParty`, 24 px tall, `campPlaces.css` sets it so) and the spellbook's
  small "Unequip" button (36 px) are still under 44 px; neither is restyled by this PR and their own sheets set the sizes.
- The camp's own small eyebrow lines ("The enemy below", "The War Council", 8 to 9 px) and some party and castle labels are under 11 px already on main.
