# Notes index

One note per topic, named after it. A note records what was built when it was built; where a later change replaced it, the note
carries a **Status** line at the top. The notes that were superseded by the retirement of the endless tower (the "spire") are:
`rogue-tower`, `tower-elites`, `tower-look`, `tower-reset` and `tower-twists` (all now the Calamity's map engine; the Last Stand,
`last-stand.md`, took the tower's place at the camp), and `summon-stones` (codex entries no longer pay stones, `repo-accuracy.md`).
